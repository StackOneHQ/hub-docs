## **Docebo**

Content in Docebo shows as type tincan ([Tin Can API](https://xapi.com/overview/)). The content flow works in exactly the same way as other integrations.

The user will be redirected to the external content provider platform and the progress will be tracked via the User Completions endpoint.

<Warning>
Docebo does not allow updating content URLs or image URLs via the upsert content endpoint.
</Warning>

## **360 Learning**

**Summary**

360 Learning will automatically create a completion on content launch. This isn't configurable.

The completion is initially created with 1% completion. When you create a completion via StackOne we will update this progress to 100%.
