## **Summary**

The Xyleme integration allows you to pull curated content from your customer's Xyleme platform and display it in your LMS/LXP.

It integrates content, users, user progress and pulls in extensive metadata.

To ensure the content and completions pulled in are concise and specific to the integration, you should discuss with Xyleme prior to connecting. This discussion should cover the classification tag that will be used to identify content accessible by the integration.

You should then enter this classification when enabling the integration. This tag will be the same for all customers using the integration.
