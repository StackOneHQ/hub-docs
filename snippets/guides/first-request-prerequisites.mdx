## Prerequisites

1. [**API Key created in StackOne Dashboard**](https://docs.stackone.com/embed/api-keys) and copied to a secure location

2. [**Basic Authentication Setup**](https://docs.stackone.com/platform-api/authentication) - Learn how to properly authenticate with StackOne API using your API key

3. Required provider integration enabled

4. Account linked successfully

5. (Optional) Use an [SDK](https://docs.stackone.com/platform-api/api-sdks)
