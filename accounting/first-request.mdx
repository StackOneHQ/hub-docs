## Making Your First Request

Now you're ready to make your first Accounting API call. Let's list accounts from the connected accounting system:

<Tabs>
  <Tab title="cURL">
    ```bash
    curl --request GET \
      --url 'https://api.stackone.com/unified/accounting/accounts' \
      --header 'accept: application/json' \
      --header 'authorization: Basic {base64_encoded_api_key}' \
      --header 'x-account-id: {account_id}'
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { StackOne } from "@stackone/stackone-client-ts";

    const client = new StackOne({ apiKey: "YOUR_API_KEY" });

    const response = await client.accounting.listAccounts({
      xAccountId: "your-account-id"
    });

    console.log(response.accounts);
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from stackone_client import StackOne

    client = StackOne(api_key="YOUR_API_KEY")

    response = client.accounting.list_accounts(
        x_account_id="your-account-id"
    )

    print(response.accounts)
    ```
  </Tab>
</Tabs>
